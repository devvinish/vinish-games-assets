# vinish-games-assets

Models, textures and sounds for the games on [vinish.dev](https://vinish.dev), one folder per game.
Games load them through jsDelivr from a tag per game, for example:

    https://cdn.jsdelivr.net/gh/devvinish/vinish-games-assets@glassback-v1/glassback/models/gb-anims.glb

Each game folder has a `CREDITS.md` with the source, author and licence of every file.
A new tag (`<game>-v2`, `-v3`, ...) is made for every change to a game's assets, so pages that use an older tag keep working.
