# REDLINE RUN — asset credits

REDLINE RUN is an original game by vinish.dev. Its code, stages, cars, bosses, roads and roadside scenery are original and drawn in code at run time. The few third-party files below were cut, levelled and re-encoded for the game. Every source allows redistribution and commercial use.

All sources are **CC0 1.0** (public domain dedication), except the Silkscreen font, which is under the **SIL Open Font License 1.1**. Its licence is shipped next to the font as `OFL-silkscreen.txt`. CC0 needs no credit, but we credit the authors anyway, with thanks.
